Repository Architecture & Technical Specs

Deep-dive structural breakdown of this static client-side single page application.

Technical Architecture

The application is engineered strictly as a client-side Single Page Application (SPA) requiring zero external server runtime. All state management, routing, score calculation, and text matching run deterministically in the browser engine.

Styling & Tokens Tailwind CSS + Custom Glassmorphism
Icon System Lucide Icons (vLatest)
Routing Vanilla Hash Routing (#overview, #exams, etc.)
State Engine Decoupled ES6 Classes & LocalStorage Sync

Decoupled Data Architecture

Data layers are decoupled into clean standalone modules with no circular dependencies:

assets/js/exams-data.js
5 complete exams, 37 questions, 4 options each, correct answers, step-by-step mathematical & linguistic explanations.

10 distinct AI newsletters with key takeaways, category badges, read times, and comprehensive technical write-ups.
assets/js/chatbot.js
Offline NLP keyword and intent classifier with synonym matching and Sahyadri College factual knowledge base.

NexusLab Contributor Onboarding Guide

Zero-code maintenance guide for non-coders, first-year peers & project teammates

No Coding Required — Visual & JSON Modes

Any teammate or first-year peer can inject aptitude quizzes or short 5-8 minute JLPT Japanese flash assessments directly inside the browser.

1
Click "+ Create / Attach Test" on Exam Hub Open the modal. You can choose between the interactive visual builder or quick JSON paste.
2
Configure Title, Category & Timer Set your test title (e.g. "JLPT N5 Kanji Flash Quiz"), choose category, and specify duration (e.g. 8 minutes for speed flash drills or 15 mins for full mock).
3
Add Questions, Options & Mark the Correct Answer Fill in 4 options (A, B, C, D) and simply click the radio toggle next to the right answer. Add an explanation if you want.
4
Save to LocalStorage & Sync via JSON Export Click "Save & Attach Test". Your test is live immediately! To commit it permanently into the GitHub repo, click "Export All Tests (JSON)", paste into assets/js/exams-data.js, and push to main.

Post Daily AI Breakdowns in 2 Minutes

Keep the dashboard updated daily with the latest AI discoveries without writing any HTML or JavaScript.

1
Click "+ Publish Today's News" Located in the AI Newsletters module header.
2
Enter Headline, Category & Key Takeaways Provide a 2-sentence executive summary and 3 key takeaways (one per line). These will render as sleek highlight pills on the card.
3
Write Full Analysis Body Full Markdown support! You can use ### Section, - bullet points, and code blocks.
4
Commit via "Export Newsletters (JSON)" Clicking "Export Newsletters (JSON)" puts the full updated dataset on your clipboard ready to paste into assets/js/news-data.js.

Offline NLP Knowledge Base Expansion

The Sahyadri Assistant uses an offline keyword-intent matcher in assets/js/chatbot.js. Here is how any student can add new FAQs (bus routes, sports fests, lab equipment).

Knowledge Item Schema: 
{
  id: 'campus_bus_transit',
  intent: 'College Transit & Bus Fleet',
  keywords: ['bus', 'route', 'pickup', 'transport', 'commute', 'driver', 'timings'],
  response: `
**Sahyadri College Bus & Transit Fleet:**

- **Coverage:** Regular bus services operating across Mangaluru, Surathkal, Bantwal, Udupi, and Kasaragod.
- **Timing:** Arrives at campus by 8:45 AM; departures at 5:00 PM.
- **Office:** Contact the Transit Desk at the Main Administrative Block.
  `,
  followUps: [
    'Campus location & Netravati Riverside',
    'What are the CET codes?',
    'Campus amenities & facilities'
  ]
}
Simple 3-Step Contribution Workflow:

1. Open assets/js/chatbot.js.

2. Add your new object inside the this.knowledgeBase = [ ... ] array.

3. Test immediately by refreshing the page in your browser. Send a GitHub PR once confirmed!
